# Work tagging decisions

## Scope vocabulary (decision:tagging/scope-vocabulary)

**Open.** Whether scopes are a small set blizzard ships and documents or scopes an operator defines, and whether an
unknown scope is an error or ordinary; it blocks `product:scoped-tags`.

## Untagged chunks (decision:tagging/untagged-chunks)

**Open.** What a chunk with no tags means to a runner that accepts only some: taken by default, or left alone; it blocks
`product:runner-tag-filter`.
