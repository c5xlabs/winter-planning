# Initiatives

These are the durable outcomes Winter Workspace is investing in, not a status board. Each initiative owns its scope and
the epics that contribute to it.

| Initiative                                                                       | Outcome                                                                                                                                   |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| [`initiative:parallel-workspaces`](./work/parallel-workspaces/initiative.md)     | Engineers create and manage isolated multi-repository work without losing another task's branches, files, or workspace settings.          |
| [`initiative:running-environments`](./work/running-environments/initiative.md)   | Each feature environment reaches a prepared, running state with isolated resources and services that can be inspected and safely stopped. |
| [`initiative:agent-ready-operation`](./work/agent-ready-operation/initiative.md) | Agents and operators receive consistent guidance, harness tooling, and trustworthy observations before choosing what to change or run.    |
| [`initiative:rust-adoption`](./work/rust-adoption/initiative.md)                 | Existing users deliberately adopt a verified, installable Rust replacement while preserving their work and supported integrations.        |
